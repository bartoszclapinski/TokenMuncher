See how much of your AI coding plan is left.

TokenMuncher is a small Windows app that watches your Claude Code, Cursor, Codex and GitHub Copilot limits: how much you have used, how fast you are burning tokens, and whether you will make it to the next reset. It also counts Gemini CLI tokens and sessions.

Keep an eye on it while you work

  • Mini widget: a small always-on-top window with your limits and the current burn rate.

privacy

Your usage data stays on your computer

  • Logins are only read from each tool's own files and sent only to that tool's own server. They are never stored, logged or refreshed.
  • No telemetry, no analytics. The only other request is the update check and download from GitHub.
  • Open source: what is read and sent where is documented, and you can read the code.

install

Up and running in a minute

  1. Download the installer from the latest release.
  2. Run it. It installs for your Windows user only, with no administrator rights.
  3. Look at the tray, next to the clock. Click the critter to show or hide the window.

The installer is not code-signed, so Windows SmartScreen may warn about an unknown publisher: choose More info, then Run anyway. Each release lists the SHA-256 of its files. The app updates itself from GitHub releases.
